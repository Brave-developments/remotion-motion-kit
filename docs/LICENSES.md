# Licensing and provenance rules

The material in this tracked motion-kit folder is newly created documentation and original code. Upstream libraries live outside tracked content until selectively copied.

The downloader checks out five upstream projects that state MIT in their documentation, preserving their own source and notices. Before copying individual files into a redistributed app, verify the actual LICENSE text, preserve copyright and SPDX headers, and inspect nested images/icons/fonts/audio/trademarks for separate rights.

RVE templates README states MIT but its root listing did not show a separate LICENSE file at review. It remains catalogued only by default. Official Remotion Agent Skills should be installed via the official skills CLI, not copied blindly into a commercial asset archive.

**Remotion core is not simply MIT licensed.** Read https://www.remotion.dev/license for current individual/company eligibility. Public YouTube footage, X posts, screenshots, news images and songs are not automatically reusable merely because they are online. Keep author, source, date, permitted-use basis and approval in the app.

The original SVG and custom code in this kit may be used in FlashCut AI. The kit is not affiliated with the upstream library makers.
